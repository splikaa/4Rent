========================================================================
   4Rent Management System v1.0.1 — Official Desktop Launchers
   Windows (.EXE / .ZIP) & macOS (.APP / .ZIP / .COMMAND)
========================================================================

1. WINDOWS DESKTOP (`Windows 10 & Windows 11`)
   - Extract `4Rent-Desktop-Windows.zip` or place `4Rent-Launcher.exe` in any folder.
   - Double-click `4Rent-Launcher.exe` (no installation or administrator rights required).
   - Click "Launch 4Rent Standalone Desktop App" to open 4Rent in a dedicated borderless
     desktop window, or click "Pin to Desktop" to create a permanent Desktop shortcut.

2. macOS DESKTOP (`Apple Silicon M1–M4 & Intel Mac — Zero CLI Required`)
   - Unzip `4Rent-Desktop-macOS.zip`.
   - Option A (Standard macOS App): Double-click `4Rent.app` and choose
     "Install to Applications & Launch", or drag `4Rent.app` into `/Applications`.
   - Option B (1-Click Setup): Double-click `Install 4Rent to Applications.command`
     to automatically install `4Rent.app` to `/Applications`, clear Gatekeeper quarantine
     flags, create a Desktop shortcut, and launch the app.

3. MULTI-DEVICE CLOUD SYNCHRONIZATION (DESKTOP <-> MOBILE)
   - Open Settings -> Cloud Database Sync on Desktop and Mobile.
   - Enter the same Property Space Code on both devices and tap "Sync Now".
   - Offline rooms, meter readings, receipts, and Configurations sync automatically
     whenever Wi-Fi or Mobile Data is active.
